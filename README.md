# Scientific Calculator

A simple Scientific Calculator built using HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations
- Square root calculation
- Power calculation
- Percentage operation
- Responsive dark mode UI

## Technologies Used

- HTML
- CSS
- JavaScript
